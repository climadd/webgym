# 🏋️ Local Gym Business Website

A practical, fully responsive website developed for a local gym business.  
The project provides essential business information, enhances customer engagement, and establishes a strong digital presence.

Built with **HTML, CSS, and JavaScript**, alongside a **PHP-based backend**, this project demonstrates front-end development skills, responsive design principles, and database integration for dynamic content management.

---

## 📌 Project Overview

This website was designed to present the gym’s services in a clear and structured way while maintaining a modern and user-friendly interface. The platform improves client engagement through interactive components and ensures full responsiveness across desktop, tablet, and mobile devices.

A key feature of the project is its backend integration. Users can submit content directly through the website (such as inquiries via the contact form), and the system automatically stores the submitted data in structured database tables. This enables efficient tracking, organization, and future scalability of the platform.

---

## 🌐 Website Structure

### 🏠 Homepage

The homepage introduces the gym through a responsive and adaptive navigation bar, promotional highlights displayed via a carousel-like component, and a clean overview section that reflects the brand identity. A structured footer provides quick access to essential links and contact information.

### 🏋️ Coaching Page

The Coaching page presents detailed information about the trainers and the services offered. It highlights coaching specialties and provides visitors with a clear understanding of the gym’s professional expertise.

### 🗓 Schedule & Location Page

This section displays the weekly class schedule and opening hours in an organized format. An embedded map allows users to easily locate the gym, improving accessibility and convenience for potential clients.

### 📩 Contact Page

The Contact page features a functional inquiry form with both client-side validation and backend processing. Once a user submits the form, the system automatically creates a corresponding database entry containing a unique ID, timestamp, and user-provided information.

---

## 💻 Technologies Used

### Frontend

The front-end of the project was built using:

- **HTML** for structure  
- **CSS (Flexbox & Grid)** for layout and responsive design  
- **JavaScript** for interactivity and dynamic behavior  

### Backend

The backend is implemented using **PHP**, following a structured and modular approach inspired by RESTful architecture principles. It handles data processing, validation, and database communication.

### Database

The system includes structured database tables designed to store:

- User inquiries  
- Website content submissions  

This architecture ensures clean data organization and easy scalability for future feature expansion.

---

## 🗄 Database Integration

The project integrates a relational database that automatically records user interactions. Each form submission generates:

- A unique identifier  
- A timestamp  
- The user’s submitted data  

This approach guarantees persistent storage, administrative tracking capabilities, and a foundation for future analytics or reporting tools.

---

## 📱 Responsive Design

The website is fully responsive and optimized for desktop, tablet, and mobile devices. Layouts are built using flexible structures, ensuring consistent spacing, readable typography, and intuitive navigation across different screen sizes.

The responsive navigation system adapts dynamically to smaller screens, maintaining usability without compromising design quality.

---

## 🔐 Validation & Security

Basic security practices were implemented to ensure safe data handling. The project includes client-side form validation and secure database connections to protect user-submitted information and maintain data integrity.
